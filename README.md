# Dev Showcase

Create a modern, professional catalog website to showcase my work as a freelance full-stack developer. The website should serve as my digital portfolio, highlighting my projects, technical skills, services, and expertise in building end-to-end web applications. Include visually appealing project cards, detailed case studies, technology stack badges, and clear calls to action for potential clients to discuss their projects or hire me. The overall design should be clean, responsive, user-friendly, and visually engaging, with a strong focus on presenting my work and converting visitors into freelance clients.
